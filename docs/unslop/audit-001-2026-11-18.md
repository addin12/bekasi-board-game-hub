# unslop audit 001 (2026-11-18)

## Method and scope

- Method: we applied the rules in `skills/unslop/SKILL.md` and `references/signs.md` by hand to the live design. The source is github.com/heydamir/unslop (CC BY 4.0, by Damir Sokolovsky).
- Scope: the owner chose **copy and details only**. The look stays. This covers the weights, uppercase labels, thick card outline, and filled category icons. They come from the owner's own player card sketch.

## Direction (five lines)

- **Product:** a hub where Bekasi board gamers make a player card, find each other, open tables, and log plays.
- **Character:** friendly, exact, local.
- **World:** game tables, score sheets, café tables.
- **Moments:** the player card and its example on the home page.
- **Signature:** round game tokens with an ink ring, and numbered black markers.

## Found during the check

The admin content page imported a value from a server-only module. The page never became interactive, so its delete buttons did nothing. We fixed this. Every page now sets a "ready" marker so tests catch this fault.

## Not changed (owner's decision)

We did not change these items: heavy weights, uppercase labels, the 3px card outline with offset shadow, and filled colored category icons. To unslop them, use these steps:

1. Use sentence case.
2. Use weights 400 to 600.
3. Use a hairline border.
4. Use plain icons on the card.
