# unslop audit 001 (2026-11-18)

Method: the rules in `skills/unslop/SKILL.md` and `references/signs.md` from github.com/heydamir/unslop (CC BY 4.0, by Damir Sokolovsky), applied by hand to the live design.
Scope chosen by the owner: **copy and details only**. The look stays (weights, uppercase labels, thick card outline, filled category icons), because those come from the owner's own player card sketch.

## Direction (the five lines)

- **Product:** a hub where Bekasi board gamers make a player card, find each other, open tables and log plays.
- **Character:** friendly, exact, local.
- **World:** game tables, score sheets, cafe tables.
- **Moments:** the player card (and its example on the home page).
- **Signature:** round game tokens with an ink ring, and numbered black markers.

## Audit and outcome

| Group | Finding | Outcome |
|---|---|---|
| Surfaces and color | No hue gradients, glows, blobs or neon borders. One accent (brand orange) | Clean, no change |
| Type | Weights 700 to 800 on headings and labels | Kept on purpose (sketch) |
| Type | Uppercase labels (card name, category labels, wordmark) | Kept on purpose (sketch); no wide tracking |
| Type | Negative letter spacing on the small wordmark | Fixed |
| Type | Numbers without tabular figures | Already tabular |
| Icons | Sizes from 12 to 28px, mixed strokes | Fixed: one `icon` class, 18px, 1.5 stroke. Glyphs inside tokens (checkmark, trade arrows, the "+" button) stay |
| Icons | Emoji as icons | None |
| Spacing | Off-grid values (6px and 10px steps) in 9 places, an 11px text size | Fixed to the 4px scale |
| Copy | About 100 single-sentence strings ending in a period (toasts, hints, errors, empty states) | Fixed. Two-sentence messages and the legal pages keep their periods |
| Copy | Greeting headlines, exclamation marks, hype words, unverified claims | None |
| Copy | Mock data | Plausible, marked as demo on the sandbox |
| Components | Glowing pills, `New` badges, sparklines in stat cards | None. The admin overview tiles are a number and a label only |
| Motion | Looping or bouncy motion, `transition-all`, `hover:scale` | None. One progress bar, color transitions only |
| Layout | Stacked and centered hero, three-button hero | None. Split hero, one action |
| Template check | Would the screen fit another product if the name were swapped? | No: the card sketch, tokens and markers are specific |

## Found while checking

- The admin content page imported a value from a server-only module, so it never became interactive (its delete buttons did nothing). Fixed, and every page now sets a "ready" marker so tests catch this.

## Not changed (owner's call)

Heavy weights, uppercase labels, the 3px card outline with offset shadow, and filled colored category icons. If you want these unslopped too, the next step is sentence case, weights 400 to 600, a hairline border and plain icons on the card.
