## Findings, ranked

### HIGH

**H1. The site sends no browser security headers.** `workers/app.ts:12-17`.
The request handler returns the page as the framework built it. It adds one header, and only on the sandbox. A `curl -I` on the real site shows no `Content-Security-Policy`, `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options` or `frame-ancestors`, or `Permissions-Policy`. I found no XSS sink, so this is not exploitable today. The headers are the backstop if one appears.
**Impact:** a future XSS bug has no second barrier. Any other site can put the pages in a frame (clickjacking on the sign-in and admin pages).
**Fix:** add the headers in `workers/app.ts`. Start with `nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, and `frame-ancestors 'none'`. Add a CSP in report-only mode with a per-response nonce (the React Router server entry supports a nonce). Enforce it after you read the reports. Add a unit test that asserts the headers.
Severity reason: the skill names the CSP as the highest-leverage web control.

**H2. The only copy of the code is on this PC.** `git remote -v` prints nothing.
The repository has 26 commits and no remote. The Cloudflare secrets cannot be read back from Cloudflare. The real `BETTER_AUTH_SECRET` and the real VAPID keys were never saved anywhere.
**Impact:** a disk failure or a lost PC destroys the code, the decisions log, and the secrets. Losing the auth secret invalidates all sessions and the member passcode. Losing the VAPID private key invalidates every phone subscription.
**Fix:** push to a **private** GitHub repository. Keep `.dev.vars` and the production secrets in a password manager. Write down in the README that the secrets can be replaced and what each loss breaks.

### MEDIUM

**M1. Nobody tested the backup story.** No export script exists.
The only recovery for the database is D1 Time Travel (7 days, same account, free plan). Pictures in R2 have no copy. Nobody ran a restore.
**Impact:** an admin delete, a bad migration, or an account lock after day 7 loses data for good.
**Fix:** a weekly `wrangler d1 export` to a private place, plus a restore drill on the sandbox. Write the steps in a runbook. Deferred-but-gating: this becomes HIGH when real members and photos exist. The real database holds 1 user now.

**M2. Picture uploads trust the browser.** `app/lib/.server/common.ts:29-38` and `app/lib/.server/card-actions.ts:35`.
The code checks `file.type`, which the client sets. It does not check the first bytes of the file, and it keeps all metadata.
**Impact:** a JPEG from a phone carries GPS coordinates. The privacy page says "we show your district, never an address". A photo can show an address anyway. The site also accepts a file with a wrong type as a picture.
**Fix:** check the magic bytes (JPEG `FF D8 FF`, PNG `89 50 4E 47`, WebP `RIFF....WEBP`). Delete the EXIF segment from JPEG and WebP before storing. Add tests with a GPS-tagged sample file.

**M3. The privacy page is out of date.** `app/routes/privacy.tsx:17-21`.
Phase 4 added data that the page does not list. The new data is: the push endpoint of each device, the play-style result, and Gmail as the sender of sign-in codes.
**Impact:** the page says what we keep, and this is now wrong. This is a legal and trust problem.
**Fix:** add three lines. A lawyer must still review the page. Account deletion already deletes the push rows (foreign key cascade).

**M4. No lint, no CI, no committed end-to-end tests.** No `.github/`, no ESLint config.
19 of 20 server modules have no direct test. The live click-through scripts (gate, gate2 to gate6) sit in a temporary folder and will disappear.
**Impact:** a regression in a server action reaches the real site. The skill expects lint, tests, and a secret scan in CI at Tier 1.
**Fix:** move the Playwright scripts into `tests/e2e` and run them against the sandbox with one command. Add a GitHub Action with typecheck, unit tests, and a secret scan after H2.

**M5. A member can spam another member's phone.** `app/lib/.server/tables.ts:50,61` and `app/lib/.server/feed.ts:104-110`.
Joining and leaving a table each send a bell message and a phone push to the host, with no throttle. Comments allow 60 an hour, and each one sends a push.
**Impact:** abuse behind sign-in. It also costs D1 writes.
**Fix:** one notice for each member and table in 10 minutes, and a lower comment limit for a member's own post. Mute repeated pushes with the existing `tag`.

### LOW and DEFERRED

**L1. The admin check does not require a verified email.** `app/lib/.server/viewer.ts:19`.
Both sign-in methods prove ownership of the address, so I found no way to exploit it. **Fix:** also require `emailVerified`.

**L2. One secret serves two jobs.** `app/lib/.server/passcode-store.ts:10,27`.
`BETTER_AUTH_SECRET` signs sessions and also keys the passcode hash. **Fix:** use a separate `PASSCODE_KEY` secret.

**L3. Advisories in development tools.** `npm audit`: esbuild dev server (GHSA-67mh-4wv8-2f99) through `drizzle-kit`, and minimatch denial of service through `shadcn`. Neither runs in the Worker. **Fix:** update when the tools publish a fix. Move `shadcn` to development dependencies.

**L4. Unused code and packages.** `package.json:29,31` (`isbot`, `motion`: 0 imports). `app/lib/gradient-engine` (452 KB), `app/components/charcoal-satin.tsx`, `app/components/gradient-surface.tsx`, and `design-kit/` (548 KB): nothing imports them. **Fix:** delete them. Git keeps the history.

**L5. Background failures are silent.** `app/lib/.server/limits.ts:83` and `app/lib/.server/push.ts:50` end a failed background job with no log. **Fix:** log the error name, never personal data.

**L6. A page view changes data.** `app/routes/notifications.tsx:16` marks messages as read when the page loads. A link prefetch can mark them. **Fix:** mark them in a POST.

**L7. Pictures need no sign-in.** `app/routes/img.ts:8`. The feed is for members, but a picture link opens for anyone who has it. The names are random, so nobody can guess them. **Fix:** accept this and say so in the privacy page, or check the session.

**L8. The banner is outside a landmark.** `app/routes/shell.tsx:70,74`. axe reports "region" (moderate) on all 28 pages. **Fix:** put the banner inside the `header` element.

**L9. Untyped XML data.** `app/lib/bgg-parse.ts:36,55,63,69,87` use `any`. **Fix:** parse with zod.

**D1. No "download my data".** Account deletion exists. A data-access export does not. Indonesia's data protection law gives members a right of access. Ask a lawyer when the community grows.

**D2. Community-wide queries have no `LIMIT`.** `app/lib/.server/cards.ts:117` (`gamePeople`) and `:153` (`findPeople`). Rows read grow with members. D1 allows 5 million rows a day. Promotion trigger: more than about 300 members. **Fix:** paginate and cache.
